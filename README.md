## Features
- Download videos from YouTube and other platforms
- Choose between video and audio-only downloads
- Select download quality and format
- Download entire playlists
- Resume interrupted downloads

## Installation
* Click on the releases tab and download the latest EXE file.
* Extract the zip file.
* Launch "ytBro.exe" file and start downloading videos/audios.
